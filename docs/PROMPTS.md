# 制作提示词

## 1. 视频创作

参考 https://www.boardui.com/zh-hans 的公开图表 UI。制作一支 15 秒、1920×1080、60fps 的图表动效知识短片。延续 Cards in Motion 的编辑式排版：Georgia 斜体英文大标题、Noto Sans SC 中文、纸白与墨黑场景交替。开头采用饱和橙 #ef4e24，不能太淡，第一帧就有大字和完整图表。

顺序讲解：柱状比大小、折线看趋势、环形看占比、雷达比维度、热力看密度。每种只讲一个用途，短句清楚，节奏快速。开场和结尾必须同时展示五种图表，标注名称与编号，避免写五种却只展示三种。结尾：「让数据，一眼看懂。」所有数字明确标为演示数据，图形比例、数值及提示保持一致。

## 2. 代码与导出

使用 HTML Canvas 绘制，暴露 window.draw(t)，画面完全由 t 决定；视频绘制不用 requestAnimationFrame、Date 或未设种子的随机数。等待本地字体加载完成再渲染。Playwright 逐帧导出 900 张 JPEG；先看九个关键帧，修正布局、遮挡和图表数值。Python 在 128 BPM 下合成 32 拍配乐与转场音效，结尾淡出。FFmpeg 将全范围 JPEG 转为 TV 范围 yuv420p，编码 H.264 Main + AAC，启用 faststart。检查 15 秒时长、画面和浏览器播放，打包源码。

## 3. 交互演示网页

制作与视频一致的五种图表交互实验室。复用影片的绘制函数、颜色、字体与示例数据；柱状悬停聚焦月份，折线指针滑过显示数值，环形悬停或点击选择来源，雷达支持上期对比开关，热力可选择格点查看次数。支持点击标签切换图表、动效重播、方向键与手机点按。无构建步骤，静态页面可在 GitHub Pages 上运行。视频章节提供原片播放与下载，README 放动态预览并附制作提示词和步骤。
